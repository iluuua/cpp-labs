# Лабораторные по C++

Мои решения лабораторных работ по C++ и задач к лекциям про рекурсию и быструю сортировку. Каждое задание оформлено отдельной консольной программой, всё собирается одним CMake-проектом.

## Что где лежит

| Папка | Тема | Программы |
|---|---|---|
| `lab01_basics` | вывод в консоль, переменные и типы, константы, арифметика, побитовые и логические операции | `lab01_hello`, `lab01_variables`, `lab01_operators` |
| `lab02_control_flow` | ввод с клавиатуры, if и switch, циклы, массивы, ссылки, функции, static, пространства имён, макросы, вынос функции в .h и .cpp | `lab02_conditions`, `lab02_loops`, `lab02_functions`, `lab02_modules` |
| `lab03_pointers` | указатели, обход массива указателем, константные указатели, указатели на функции, new и delete | `lab03_pointers`, `lab03_function_pointers` |
| `lab04_classes` | класс оружия: конструкторы, деструктор, перегрузка методов, закрытые поля, дружественный класс, статические члены | `lab04_classes` |
| `lab05_inheritance` | перечисление, структура, наследование, виртуальные методы, перегрузка операторов, абстрактный класс, шаблон класса | `lab05_inheritance` |
| `lab06_exceptions` | try и catch, стандартные исключения, свой класс исключения с кодами ошибок | `lab06_number_words`, `lab06_birth_year`, `lab06_custom_exception` |
| `lab07_stdlib` | строки, регулярные выражения, cmath, запись и чтение файла, vector и map | `lab07_strings`, `lab07_regex`, `lab07_math_and_files`, `lab07_containers` |
| `lecture_recursion` | четыре задачи на рекурсию, без циклов и массивов | `recursion_count`, `recursion_range`, `recursion_digit_sum`, `recursion_prime_factors` |
| `lecture_quicksort` | быстрая сортировка своими руками и `qsort` из стандартной библиотеки | `quicksort_thousand`, `quicksort_50_100`, `quicksort_matrix_column`, `quicksort_students_qsort` |

В начале каждого `.cpp` написано, к какому заданию он относится.

## Сборка

Понадобятся CMake 3.16 или новее и компилятор с поддержкой C++17: GCC, Clang или MSVC из Visual Studio 2019 и новее.

```bash
cmake -S . -B build
cmake --build build
```

Если тип сборки не указать, CMake соберёт Release. Готовые программы появятся в `build/bin` (у Visual Studio в `build/bin/Release`). Запуск, например, так:

```bash
./build/bin/lab02_conditions
```

В Visual Studio можно ничего не набирать в консоли: File > Open > Folder, выбрать папку репозитория, и VS сама подхватит CMakeLists.txt.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

Тест запускает программу, подаёт ей заранее заготовленный ввод и проверяет, что в выводе есть нужная строка. Например, калькулятору из лабы 2 подаётся `8`, `4`, `*` и ожидается `8 * 4 = 32`. Те же тесты гоняются в GitHub Actions на Linux, macOS и Windows после каждого пуша.

## Мелочи, о которых стоит знать

Русский текст в консоли Windows по умолчанию ломается, поэтому каждая программа первым делом вызывает `setupConsole()` из папки `common`. Функция переключает консоль на UTF-8. В Linux и macOS она ничего не делает, там всё работает и так.

В лабе 7 строка перед `substr`, `find` и регулярным выражением для имени переводится в `std::wstring`. В UTF-8 русская буква занимает два байта, и обычный `substr(1, 3)` резал бы буквы пополам.

Задача про простые делители выводит их с повторами: для 12 получится `2 2 3`.

В задаче про двумерный массив сортируется только первый столбец, остальные числа остаются на своих местах.
